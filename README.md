## 📌 Overview

**LeetCode Analyzer** is a web application that provides insightful visualizations of your LeetCode profile data. It helps you track your problem-solving progress, identify strengths and weaknesses, and stay motivated on your DSA journey.

Simply enter your LeetCode username, and the app will fetch your stats using an API and display them in an organized, user-friendly interface.

---

## 🚀 Features

- 📊 Visual breakdown of solved problems by difficulty
- 🧠 Recent submissions overview
- 🧩 Detailed stat summary (ranking, contribution points, etc.)
- 🔍 Clean, responsive UI for both desktop and mobile

---

## 🖥️ Deployed at
- **Vercel:** leet-code-analyser.vercel.app

---

- **Frontend:** React.js, Tailwind CSS
- **API Integrated:** [`alfa-leetcode-api`](https://alfa-leetcode-api.onrender.com)
- **Charting:** Recharts / Chart.js

## 🧪 How to Run Locally

1. **Clone the repo**

   ```
   git clone https://github.com/your-username/LeetCode-Analyzer.git
   cd LeetCode-Analyzer
   ```
2. **Install dependencies**

   ```
   npm install
   ```
3. **Start the development server**

   ```
   npm run dev
   ```
